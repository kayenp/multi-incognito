## Optimizations and Lessons Learned:
<br>
Barebones NodeJS server runnning Express and Playwright to orchestrate the launching of custom chromium browsers for queue placements. I wanted to keep it simple and since everything is handled through the chromium instances, I didn't add a separate frontend.
